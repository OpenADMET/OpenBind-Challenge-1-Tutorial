# Boltz-2 (`v2.2.1`) Co-Folding Report — OpenBind Blind Challenge 1 (Zika Virus NS2B–NS3 Protease)

## 1. Executive Summary

All **400 blinded small-molecule ligands** (`blind_challenge_001` – `blind_challenge_400`) from the OpenBind Blind Challenge 1 dataset were co-folded with the heterodimeric **Zika virus NS2B–NS3 protease** using **Boltz-2 (`v2.2.1`)** on an `NVIDIA GB10` GPU. Five diffusion samples were generated per ligand (`2,000` total complex structures). Evaluating all 2,000 samples with **PoseBusters (`v0.6.5`)** and selecting the highest-confidence PoseBusters-passing sample per ligand achieved:

- **PoseBusters `dock` physical & geometric validity (18 checks)**: **377 / 400 (94.25%)** *(up from 299 / 400 [74.75%] at Rank-1 only — rescuing 78 ligands via multi-sample selection)*
- **PoseBusters full 22-check validity (including tetrahedral chirality vs. SMILES)**: **353 / 400 (88.25%)** *(up from 267 / 400 [66.75%] at Rank-1 only — rescuing 86 ligands)*
- **Official OpenBind Submission Validator (`validation/structure_validation.py`)**: **`✅ Submission is valid — ready to upload.`** (`0` errors across all 400 PDB structures in `openbind_zika_ns2b_ns3_boltz2_submission.zip`)

## 2. Engine, Checkpoint, Hardware & Target Specification

- **Engine**: Boltz-2 (`v2.2.1`, MIT License)
- **Model Checkpoint**: `boltz2_conf.ckpt` (MIT License, structural training cutoff **`2023-06-01`**)
- **Compute Hardware**: `NVIDIA Grace Hopper / GB10` (128 GB unified memory)
- **MSA Pipeline**:
  - Paired (`greedy`) and unpaired MSAs were precomputed once via ColabFold MMseqs2 (`zika_ns2b.csv` for Chain A, `zika_ns3.csv` for Chain B) and referenced across all 400 YAML input files generated by `make_boltz_inputs.py`.
- **Sampling Protocol**:
  - `--seed 42`, `--diffusion_samples 5`, `--output_format pdb` (`model_0.pdb` .. `model_4.pdb` per ligand; `2,000` total structures across 400 ligands)
  - Inference speed: **~7.9 seconds** per 5-sample complex (~53 minutes total wall-clock time for all 400 ligands).
- **Target Construct** (`inputs/NS2B-NS3_protein_sequence.fasta`):
  - **Chain A (NS2B cofactor, 46 aa)**:
    `SMGKSVDMYIERAGDITWEKDAEVTGNSPRLDVALDESGDFSLVEE`
  - **Chain B (NS3 protease domain, 168 aa)**:
    `MKEVKKGETTDGVYRVMTRRLLGSTQVGVGVMQEGVFHTMWHVTKGAALRSGEGRLDPYWGDVKQDLVSYCGPWKLDAAWDGLSEVQLLAVPPGERAKNIQTLPGIFKTKDGDIGAVALDYPAGTSGSPILDKCGRVIGLYGNGVVIKNGSYVSAITQGKREEETPVE`
  - **Chain C (Small-molecule ligand, residue name `LIG`)**: 400 blinded SMILES from `openbind-blind-challenge-1-TEST-BLINDED.csv`

### Execution Command

```bash
boltz predict ./boltz_inputs \
  --out_dir ./preds_boltz2 \
  --cache ~/.boltz \
  --diffusion_samples 5 \
  --output_format pdb \
  --seed 42 \
  --num_workers 4
```

## 3. PoseBusters (`v0.6.5`) Evaluation & Multi-Sample Selection ($N = 400$)

All 2,000 Boltz-2 PDB outputs (`400 ligands × 5 samples`) were standardized to OpenBind format and evaluated with PoseBusters (`v0.6.5`) via `process_boltz_submission.py`.

> [!IMPORTANT]
> Multi-sample PoseBusters filtering is particularly impactful for Boltz-2: while its top-ranked (`model_0`) sample exhibits a `24.50%` rate of close protein–ligand contacts (`minimum_distance_to_protein` pass rate `302 / 400 [75.50%]`), evaluating all 5 diffusion samples rescues **75 of the 98 clashing ligands**, boosting `minimum_distance_to_protein` to **377 / 400 (94.25%)** and overall 22-check pass rate from **66.75%** to **88.25%**.
